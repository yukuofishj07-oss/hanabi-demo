# 花火島 HANABI ISLAND (4-4-2 標準 S 型蛇行 + 100% 必現 3D 煙火 + 內建二頭身工匠範本版)

## 🛠️ 本次針對您的問題進行的關鍵根治與升級：

### 1. 為什麼之前一直看不到煙火？（已徹底根除 Bug！）
- **真正原因**：Three.js 的 `THREE.Points` 預設開啟 `frustumCulled = true`（視錐體自動剔除）。因為初始化時未啟動粒子的座標在 `Y = -9999`，導致 Three.js 誤判整個煙火系統遠在地底深處不在畫面中，直接整組跳過不渲染！
- **終極解法**：
  1. 強制設定 `frustumCulled = false`（永不剔除）。
  2. 雙重渲染：除了星芒貼圖外，同步使用 **3D 實體發光球 (`InstancedMesh` Glowing Spheres)** 繪製煙火星珠！不受任何顯示卡點大小限制，遠近都無比飽滿璀璨。
  3. 修正相機視角與爆炸高度（控制在 `Y = 7.2 ~ 11.4`），一打開網頁正中央就能看到迎賓三連發巨型花火！

### 2. 標準 4-4-2 S 型蛇行排列 + 島嶼面積放大 2 倍
- **島嶼半徑放大至 `R = 2.85`**：解決島嶼太小限縮造型問題。
- **4-4-2 標準 S 型蛇行**：
  - 第一排（後排左至右）：`01 ➔ 02 ➔ 03 ➔ 04`
  - 第二排（中排右至左）：`08 ⬅ 07 ⬅ 06 ⬅ 05`（04 順暢接 05）
  - 第三排（前排左至右）：`09 ➔ 10`（08 順暢接 09，10 號砲陣地壓軸居中）

### 3. 缺少工人？需要外部造型還是範本？
- **解答**：遵循規格書「不載入外部 3D 模型檔」原則，我們需要的是**程式內建的組合範本（Procedural Prefab Templates）**！
- 已在 `src/logistics/workers.js` 內建 `createChibiWorkerPrefab()` 二頭身黏土工匠範本（含圓臉、豆豆眼、安全帽、工裝服、雙手捧物料箱、邁步雙腿），18 位工匠沿著 4-4-2 S 型拱橋來回搬運與點頭交接！
