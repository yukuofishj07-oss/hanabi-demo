# 花火島 HANABI ISLAND (極致美化與繁中全工藝詳解旗艦版)

微縮黏土玩具模型風格的 3D 傳統花火工藝島。

## ✨ 本次重塑重大突破
1. **徹底解決「黑剪影與海面漩渦」的視覺問題**：
   - 全面修復材質色彩，建築擁有暖白黏土牆身、赤陶色四坡斜頂與木質裝飾。
   - 移除天空中粗糙的遮擋灰球，呈現清澈深邃的夜空星河。
   - 海面重構為透亮的深海琉璃色澤。
2. **完整的繁體中文傳統煙火 10 大流程解說**：
   - 點選任一工島，立即展開【工藝核心目的】、【傳統古法操作流程】與【嚴格檢驗標準】三段式深度解讀。
3. **優雅的 S 型蛇狀小島動線**：
   - 10 座工島依照 01 -> 10 的工序由左向右、再折返延伸，配合木造小拱橋串聯，步道環與微縮植栽生機盎然。
4. **璀璨實時夜空煙火**：
   - 預設每 2.5 秒於第 10 號發射陣地自動升空綻放，高亮雙層花火並同步點亮海面與島嶼。
