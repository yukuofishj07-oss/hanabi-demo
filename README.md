# 花火工藝島 (HANABI CRAFT & FESTIVAL)

微縮黏土模型風格的 3D 互動傳統尺玉花火工藝巡禮。

## ✨ 本版本五大核心亮點
1. **極簡品牌卡與 4 字深色毛玻璃島標**：
   - 左上標題定名為「花火工藝島」，移除所有工程測試代號與小標籤，乾淨大器。
   - 島嶼標籤濃縮為 `01 配藥`、`02 調色`、`03 滾珠` 等極簡深色毛玻璃徽章，不遮擋島內微縮景觀。
2. **方案 A：黃金 30° 長焦微距斜視角 + 自動軌道巡覽**：
   - 支援「◀ 上一站 ／ 下一站 ▶」、「🎬 自動巡覽」與「🔭 全景俯瞰」，鏡頭如雲霄飛車般沿著 S 型工藝鏈近距離導覽。
3. **放大兩倍的島嶼 (R = 4.2) + 10 座「會動」的微縮機關工坊**：
   - 水車連動上下舂搗的木臼、旋轉攪拌葉片的五彩調色釜、持續自轉的黃銅造粒筒、旋轉測風車、上下壓合的龍門熱壓機、自轉的同心圓剖面排珠台、翻轉纏帶機、動態 X 光掃描光環與雙層朱紅觀禮櫓。
4. **Teal & Orange 電影級冷暖光影與蓬鬆樹簇**：
   - 每座島配置真實暖橘色燈籠點光源，與深邃琉璃海面形成冷暖對比；樹木改用多球體不規則蓬鬆樹簇。
5. **流線型金絲拖尾煙火 (LineSegments Streaks)**：
   - 告別呆板的圓白點，採用多段式放射光軌與柔光星芒，於島嶼後上方夜空優雅綻放。
