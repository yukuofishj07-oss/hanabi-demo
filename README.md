# 花火島 HANABI ISLAND (工序路網與物流全真模擬旗艦版)

嚴格依據微縮黏土玩具模型規範製作，全面升級工匠物流系統：**告別原地繞圈圈，實現真實工藝環節作業**。

## 👷 核心特色：真實工藝環節與路網作業 (Non-Looping Workers)
1. **Dijkstra 跨島最短路徑尋路 (`src/logistics/pathfinding.js`)**：
   - 建立 12 座六角島與拱橋的實際拓撲路網圖。
   - 工人依據製程上下游協作關係，穿越島嶼步道與小拱橋進行物料運送。
2. **手持/頭頂物料運送與到站交接卸貨 (`src/logistics/workers.js`)**：
   - 工人攜帶對應工序的專屬物料（火藥桶、顯色藥盒、星珠曬盤、牛皮紙殼、成型彈體）。
   - 抵達目標工坊後，**自動停頓 1.4 秒進行裝卸、點頭交接確認**，完成後折返。
3. **即時物流聯動日誌 (Workshop Logistics Log)**：
   - 工人啟程、過橋、交接皆即時推播至右上角日誌面板。
4. **程序化 Web Audio 聲景**：
   - 零外載音檔，純數學震盪器即時合成升空哨音、引爆超重低音、火星脆響與日式夏夜海浪背景氛圍。

## 🚀 本地測試方式
```bash
npx serve .
# 或
python3 -m http.server 8000
```
瀏覽器開啟 `http://localhost:8000`，點擊「開始參觀花火工藝島」即可體驗！
