# 花火島 HANABI ISLAND (S 型蛇狀工藝旗艦版)

微縮黏土玩具模型風格的 3D 傳統花火工藝島。

## ✨ 本次 5 大核心改版重點
1. **取消工人與煙火聲音**：移除了路徑人偶與音效模組，回歸極致純粹安靜、高幀率 60FPS 的微縮黏土雕塑視覺。
2. **S 型蛇狀島嶼排列 (S-Curve Snake Layout)**：工島從左到右、蜿蜒向前，呈現動線清晰且極具美感的蛇狀工藝島鏈。
3. **工序精煉好懂**：梳理出 10 大傳統花火重要事蹟（黑火藥配研、顯色反應、星珠造粒、陽光乾燥、半球紙模、內膽排珠、玉張糊緊、底杯推藥、X光探傷、砲陣施放），內容完整專業且白話易懂。
4. **全面美化島嶼景觀**：
   - 每座島鋪設寬 0.28 淺磚色步道環、微縮石板紋理與白色浪花環。
   - 配置雙層微縮針葉松、櫻花粉闊葉樹、休閒木造長椅與暖光路燈。
5. **煙火璀璨奪目必能看見**：
   - 預設視角正對 S 型末端陣地與上方夜空。
   - 實裝程序發光星芒貼圖、外層主彈體 + 內蕊白金星光雙層次爆發，並照亮微縮小島海面。
