# 花火島 HANABI ISLAND (頂級旗艦盛典版)

微縮黏土玩具模型風格的 3D 互動傳統花火工藝島。

## ✨ 本次升級重大突破
1. **煙火視覺璀璨昇華**：
   - 採用 Canvas 即時程序生成「高亮星芒光暈貼圖」，徹底告別微弱小點。
   - 支援外環主彈體 (菊花/牡丹/金柳) + 內核白金蕊 (Core Burst) 雙層次引爆。
   - 升空高度提升至 13~20 公尺，夜空深邃對比強烈，伴隨水面真實點光反射。
2. **擬真人形 Chibi 工匠**：
   - 擁有頭部、安全帽、工裝軀幹、雙腿交叉邁步擺動與手上端著的物料托盤。
   - **行走路線全面重整**：走在島內寬敞平整的石板大道上，穿過拱橋進入相鄰工坊，徹底杜絕懸崖邊緣貼壁問題。
3. **正統煙火製造 12 道古法工序**：
   - 嚴格依照日本花火競技大會傳統工法梳理（火藥配比、金屬顯色、星珠造粒、竹篩乾燥、半球紙模、內膽排珠、合縫緊紮、玉張經緯纏帶、發射底杯、X光探傷、防潮密封、迫擊砲施放）。文案白話易懂，具備嚴謹工藝考據。
