# 花火島 HANABI ISLAND (生動互動強化版)

微縮黏土玩具模型風格的 3D 互動花火工藝島，完整展現 12 座工藝島嶼的製作流程與夜空盛典。

## ✨ 活潑生動特色一覽
- **2頭身大頭 Chibi 黏土工匠**：每座島嶼配置搬運工匠，具備步伐擺動、小跳步起伏與不同工種背心。
- **跨島物料輸送流光**：採用 Tube 流動 Shader，將火藥、星珠、牛皮紙帶的傳遞具象化。
- **多樣態花火物理模擬**：包含牡丹 (Peony)、錦冠菊 (Chrysanthemum) 與垂柳 (Willow)，引爆時伴隨動態點光源照亮海面。
- **CSS2DRenderer 膠囊島名標籤**：懸浮於各島上方，點擊自動觸發相機平滑飛行（800ms easeInOutCubic）。
- **即時工藝日誌 (Factory Live Log)**：自動記錄物料流向、裝填進度與發射事件。

## 本地執行
```bash
npx serve .
# 或
python3 -m http.server 8000
```
開啟 `http://localhost:8000` 即可體驗！
